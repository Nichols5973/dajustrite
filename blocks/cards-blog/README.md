# cards-blog

Custom **cards** block. Purpose: cards-blog-teasers: article teasers with 1 large featured teaser on the left and horizontal teasers stacked on the right.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per article: [article image] | [h3 title, excerpt paragraph, 'Read More' link]; row 1 renders as the featured teaser.

## Supported variations

No variations.
