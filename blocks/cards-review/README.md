# cards-review

Custom **cards** block. Purpose: cards-review-slider: customer review cards (title, star rating, text, author) in a horizontal slider with prev/next arrows.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per review: [star-rating image] | [quoted title (bold), review text, author name]. Optional page metadata 'slider-previous' / 'slider-next' sets the arrow button labels (otherwise the target review's title is used).
