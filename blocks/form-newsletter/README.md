# form-newsletter

Custom **form** block. Purpose: form-newsletter: newsletter subscription form (first name, last name, email*, industry select, submit) in a single inline row.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell: a link to the form-definition sheet (fields: firstname, lastname, email [required], industry [select with options], submit), optionally followed by a link to the submission endpoint. Labels, placeholders, options and button text come from the sheet.
